# WoW Asset Downloader

A Linux desktop application for searching, previewing, and extracting World of Warcraft assets.

## Planned features

- Search assets by name or numeric ID.
- Autocomplete suggestions and matching results.
- NPC and creature model previews.
- Transparent animated model exports (ProRes 4444 MOV).
- Maps, zones, dungeons, and raid artwork.
- Spell, ability, item, and equipment icons.
- Multiple asset sources with source attribution.

## Technology

- Python
- PySide6
- FFmpeg

## Project status

Early development. Currently building the desktop interface and integrating asset search providers.

This is an independent community project and is not affiliated with Blizzard Entertainment.
